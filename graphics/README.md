# Elka VoicePlay artwork

Original warm gold FPS gaming identity: an angular helmet, headset microphone and shield, with charcoal battlefield scenery. No waves or circuit-board motif.

| File | Use |
|---|---|
| voiceplay-icon.png | Original transparent square icon |
| ElkaVoicePlay.ico | Windows icon: 16, 24, 32, 48, 64, 128 and 256 px |
| voiceplay-horizontal.png | Original horizontal GitHub/promotional artwork |
| voiceplay-horizontal-under-1mb.jpg | Horizontal sharing copy below 1,000,000 bytes |
| voiceplay-vertical.png | Original vertical artwork, also used by the installer |
| voiceplay-vertical-under-1mb.jpg | Vertical sharing copy below 1,000,000 bytes |
| artwork-prompts.json | Exact prompts and generation method |
| exports.json | Export sizes and compression settings |

The originals were generated with the built-in image_gen tool. Export-Artwork.py performs format conversion, compression and icon-size exports only, without cropping or repainting. The app embeds its 256 px PNG and ICO copies from src/ElkaVoicePlay.App/Assets. The dark installer uses the portrait without cropping. The artwork ZIP contains this entire folder.
