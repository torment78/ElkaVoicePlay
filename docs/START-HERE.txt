ELKA VOICEPLAY — Hands-free chat for games

Windows 11 x64 | Unsigned preview | 0.7.0

GAME CHAT
Run ElkaVoicePlay.exe. Keep all files and the Models folder together.
Choose microphone, language and profile, then Apply settings.
Focus your game, hold the talk button, speak, then release.
The included Base model is ready for game chat. Medium and Large-v3 are optional.

OPTIONAL TRANSCRIPTION
Click Transcribe audio, then Download. The app gets its transcription component
from the ElkaVoicePlay GitHub release, verifies it and activates the tab.
It shares the included Base model. Standard speaker labels are in this component.
You can enable up to three microphone or speaker/loopback inputs.
Start transcription begins capture. Stop & save finishes and saves pending text.

DOWNLOADS
Choose individual optional components or Install all extras.
Game and transcription model choices are separate. Larger models are optional.
Game models use CPU; NVIDIA support is optional for transcription.

INSTALLER AND ICON
The setup EXE provides a dark installer, Start-menu shortcut and optional desktop
shortcut. The portable ZIP does not need installation.

Settings: %APPDATA%/ElkaSoft/ElkaVoicePlay/Saves
Base model: %LOCALAPPDATA%/ElkaSoft/ElkaVoicePlay/Models
New transcripts: Documents/ElkaSoft/ElkaVoicePlay/Transcripts
Downloaded components: %LOCALAPPDATA%/ElkaSoft/ElkaVoicePlay/Components
Previous VoicePlay/VoiceType settings and default transcript folders are imported
without deleting originals. Custom model and transcript paths are preserved.
Uninstall retains profiles, transcripts and downloaded components.
